# Restro Rasoi Backend Development Milestones

## Instructions

Before writing any code:

- Read and understand the attached Project Flow PDF completely.
- Treat the PDF as the single source of truth for all business logic, APIs, database design, validations, user flows, and requirements.
- Build only the requested milestone.
- Never implement future milestones unless explicitly instructed.
- Preserve the same architecture throughout the project.
- Never rewrite previously implemented modules unless fixing bugs or improving maintainability without changing functionality.
- Follow production-grade coding practices.
- Keep controllers thin.
- Keep business logic inside services.
- Keep validation inside the validators folder.
- Never trust calculations from the frontend. Always compute totals on the backend.
- Use modular, reusable, maintainable code.
- Before finishing each milestone, verify that every requirement for that milestone has been completed.

# Milestone 1 — Backend Foundation

## Goal

Set up the complete backend architecture.

### Implement

- Complete production-grade folder structure.
- Express server.
- MongoDB connection.
- Environment configuration.
- Global error handler.
- Async handler.
- Response helper.
- Logger.
- Constants.
- Utility functions.
- Middleware structure.
- Validators structure.
- Health endpoint.
- API versioning (`/api/v1`).
- Base route structure.
- Seed infrastructure.
- Production-ready configuration.
- Install and configure all required middleware.

### Do NOT implement

- Database models.
- CRUD APIs.
- Authentication.
- Business logic.

### Acceptance Criteria

- Server starts successfully.
- MongoDB connects successfully.
- Folder structure is complete.
- Architecture is ready for development.
